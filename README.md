### 機能要件
- 情報入力
    - **購入者情報**（会員か非会員か、氏名）:H
    - **チケット情報**（映画タイトル、鑑賞日時）:H
    - **購入チケット区分(単価)と区分ごとの購入枚数**:H
    - 座席選択:M

- 情報出力
    - **支払い料金の合計金額**:H
    - 提示可能なQRコード:L

- ホームページ
    - LP:H
    - 映画一覧:M
    - 座席選択画面:M
    - お支払い画面:M
    - ログイン画面:L

- ユーザー情報
    - ログイン:M
    - ログアウト:L

- データ管理
    - 購入履歴の一時保存:H
    - 映画・座席データの管理:M
    - 会員データの参照:M 

- 環境
    - google colabから動かせる:H
    - 簡単に保守ができる:M
